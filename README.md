# BAC Academy

An educational platform designed to help Algerian students prepare for the Baccalaureate exam (BAC).

The platform provides organized learning resources for different academic streams, including lessons, past BAC exams, solutions, and recommended YouTube channels.

## Features

- **Home:** Introduction to the platform.
- **Fields (Streams):** Browse the six Baccalaureate streams:
  - Mathematics
  - Experimental Sciences
  - Technical Mathematics
  - Management & Economics
  - Foreign Languages
  - Literature & Philosophy
- **Subjects:** Explore subjects available within each stream.
- **Lessons:** Access educational lessons organized by subject.
- **Past BAC Exams:** Find previous Baccalaureate examination papers.
- **Solutions:** Access solutions to past examinations.
- **YouTube Channels:** Discover useful educational YouTube channels.
- **About:** Learn more about the platform.
- **Contact:** Get in touch with the platform team.

## Project Goal

To provide Algerian Baccalaureate students with a centralized, accessible, and organized platform for finding educational resources and preparing for their final examinations.
